# A copy is a snapshot of a public recipe, not a link to it

"Add to my cookbook" makes a full, independent copy in the member's cookbook (along with the recipes it links to). It never follows the owner's later edits, so a member's changes are never undone and their cookbook keeps working whatever happens to the public recipe. The copy records which public recipe it came from only so a second add reuses it and credit stays honest, not to sync it. The cost is that fixes to a public recipe don't reach existing copies; that was accepted over the merge conflicts that following edits would bring.

## Consequences

- Switching later to copies that follow the original would mean deciding, for every existing copy, whether the member's edits or the owner's win.
